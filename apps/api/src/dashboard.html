summa (Latin: sum, total) is a small Rust CLI. It reads agent logs locally, explodes model breakdowns into rows, dedups by key, and writes one table: ccusage_events. Monthly rollups are just SQL — toYYYYMM(date).

This host is the cloud hub: machines POST with a token, the worker stamps the tenant, and usage lands in ClickHouse and MotherDuck. The analytics product of that pipeline is burn.duyet.net. D1 stores keys only.

* * *

beta & stable channels

Every master build publishes to the rolling beta tag; release-please tags are stable. Switch anytime: summa update --beta or --stable.

auto-update

summa config --set update.mode=auto checks hourly in the background while you work; the new binary is active next launch. No cron changes needed.

one table

Daily, session, block, project rows. Model breakdowns exploded. ReplacingMergeTree + DuckDB key delete keep it idempotent.

cron on the box

summa cronjob install — launchd, systemd --user, or crontab. The job runs update then import.

Telemetry keys

One telemetry_token per machine. The CLI reads it from ~/.config/summa/credentials.toml; it only needs read access to your own tenant.
